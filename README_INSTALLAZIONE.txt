PILIPILITRAVEL - MEGA CATALOGO ONLINE
======================================

Pacchetto creato per Amani Tour & Safari Zanzibar / PiliPiliTravel.

CONTENUTO DEL PACCHETTO
-----------------------
- index.html: pagina principale del catalogo
- assets/styles.css: grafica responsive
- assets/app.js: logica catalogo, carrello, WhatsApp/email, gestione prodotti
- assets/logo.svg: logo grafico locale
- data/prodotti-base.json: copia dei prodotti iniziali
- data/prodotti-base.csv: elenco prodotti e fonti

COME USARLO SUBITO
------------------
1. Estrai lo ZIP.
2. Apri index.html nel browser per vedere il sito.
3. Per pubblicarlo, carica tutta la cartella sul tuo hosting o dentro una sottocartella del sito, per esempio /catalogo/.
4. Apri l'URL: https://tuodominio.com/catalogo/index.html

COME INSERIRLO IN UNA PAGINA ESISTENTE
--------------------------------------
Puoi linkarlo con un pulsante:
<a href="/catalogo/index.html">Apri catalogo</a>

Oppure inserirlo in una pagina con iframe:
<iframe src="/catalogo/index.html" style="width:100%;height:950px;border:0;border-radius:20px;overflow:hidden"></iframe>

GESTIONE PRODOTTI
-----------------
Nel sito clicca su "Gestione prodotti".
Puoi:
- aggiungere nuovi prodotti
- modificare titolo, descrizione, categoria, durata, prezzo, inclusioni
- mettere un prodotto "in vetrina"
- segnare un prodotto come "speciale"
- eliminare prodotti
- esportare il catalogo in JSON
- importare un catalogo JSON aggiornato

IMPORTANTE
----------
Questa versione è statica e salva le modifiche nel browser tramite localStorage.
Per modifiche definitive online, esporta il JSON e aggiorna il file assets/app.js o chiedi a uno sviluppatore di collegare il catalogo a un database, Google Sheet o CMS.
